Мета курсу
Навчити студента фундаментальним знанням у галузі штучного інтелекту. Навчити створенню застосунків на Python з використанням штучного інтелекту.
Після закінчення курсу слухач буде:
  • Розуміти основні принципи штучного інтелекту та машинного навчання.
  • Працювати з даними, використовуючи бібліотеки NumPy та Pandas.
  • Застосовувати методи аналізу та очищення даних для підготовки навчальних вибірок.
  • Використовувати статистичні методи та метрики оцінки моделей.
  • Візуалізувати дані та результати експериментів за допомогою Matplotlib.
  • Реалізовувати алгоритми навчання з учителем і без учителя.
  • Створювати й навчати нейронні мережі для розв’язання прикладних задач.
  • Застосовувати згорткові мережі для розпізнавання зображень та аналізу візуальної інформації.
  • Розв’язувати задачі обробки природної мови (NLP) з використанням сучасних архітектур.
  • Розуміти влаштування та принципи роботи Large Language Models (LLM).
  • Володіти базовими та інженерними прийомами Prompt Engineering.
  • Використовувати можливості Generative AI та хмарні сервіси Google Cloud Platform (Vertex AI, Gemini, Vector Search, Agent Engine).
  • Застосовувати підхід RAG (Retrieval-Augmented Generation) для інтелектуальної роботи з даними.
  • Розробляти та тестувати LLM-агентів і створювати Generative AI-додатки з візуальним інтерфейсом.
  • Використовувати наявні LLM-моделі та API для інтеграції генеративних рішень у практичні та бізнес-проєкти.
  • Використовувати фреймворк LangChain для оркестрації LLM-запитів і виклику зовнішніх інструментів.
  • Застосовувати LangSmith для аналізу, валідації та моніторингу роботи LLM-систем.
  • Розробляти власні LangChain-ланцюжки з використанням PromptTemplate, Tools і Memory.

Модуль 8.
Generative AI та його використання в Google Cloud Platform

  1. Вступ до Generative AI.
    • Поняття Generative AI та відмінність від класичного машинного навчання.
    • Типи генеративних моделей (LLM, Diffusion, Multimodal).
    • Огляд Generative AI-рішень у хмарах (Azure OpenAI Service, AWS Bedrock, Google Vertex AI).
    • Архітектура хмарних AI-платформ.
    • Етичні аспекти та ризики використання генеративних моделей.
  2. Основи Prompt Engineering.
    • Що таке промпт і навіщо він потрібен у роботі LLM.
    • Типи промптів: інструктивні (Instruction), ролеві (Role), діалогові (Conversational), демонстраційні (Few-Shot).
    • Принцип структури prompt-запиту:
      Роль -> Контекст -> Завдання -> Формат відповіді.
    • Як формулювати задачі для LLM:
      • Конкретні дієслова ("створи", "поясни", "проаналізуй").
      • Явне обмеження обсягу й тону відповіді («не більше 3 речень», «формальний тон»).
      • Вказівка цільової аудиторії ("для студентів / для розробників / для менеджерів").
    • Як задати формат виводу (список, таблиця, JSON, код).
    • Помилки новачків: двозначність, відсутність контексту, надто загальні запити.
  3. Патерни та прийоми Prompt Engineering.
    • Zero-Shot / Few-Shot / Chain-of-Thought / Self-Consistency.
    • ReAct (Reason + Act) — покрокове міркування та виконання дій.
    • Tree-of-Thought (TOT) — розгалужене мислення та самооцінка варіантів.
    • Reflexion / Critic / Editor Pattern — самоперевірка та редагування відповідей.
    • Persona Pattern — призначення ролі (експерт, учитель, аналітик, асистент).
    • Template Pattern — підказки з змінними ({context}, {goal}, {format}).
    • Output-Guidance Pattern — точне завдання формату відповіді.
  4. Оптимізація та управління контекстом.
    • Контекстне вікно та його обмеження (довжина, вага фрагментів).
    • Контроль історії діалогу та модульний підхід: інструкції + дані + задача.
    • Прийоми контрольного зниження галюцинацій (переформулювання, валідація, перевірка фактів).
    • Промпт-бібліотека для типових кейсів (аналітика, QA, контент, код-ревью).
  5. Архітектура та можливості GCP Vertex AI.
    • Що таке Google AI Studio (Standalone)?
    • Що таке Vertex AI?
    • Відмінність між Google AI Studio (Standalone) і Vertex AI в GCP (проєкти, квоти, білінг).
    • Компоненти Vertex AI: Gemini API, Embeddings, Vector Search 2.0, Model Garden.
    • Сімейство моделей Gemini 2.0 / 2.5 (Flash, Flash-Image та ін.); життєвий цикл і міграція моделей.
    • Express mode: швидкий старт з обмеженими квотами та строком; для продакшена потрібен білінг.
    • Підключення через Python SDK (google-cloud-aiplatform).
    • Практичні приклади використання.
  6. Робота з даними та RAG у Vertex AI.
    • Концепція RAG (Retrieval-Augmented Generation).
    • Використання Vector Search 2.0 для індексації даних.
    • Створення Knowledge Base в Agent Builder / AI Applications.
    • Інтеграція зовнішніх даних (тексти, PDF, CSV).
    • Практичні приклади використання.
  7. LLM-агенти та оркестрація.
    • Поняття AI-агента та його архітектура (інтерфейс -> LLM -> інструменти -> дані).
    • Vertex AI Agent Engine (GA) і Agent Builder / AI Applications: архітектура, ADK-плагіни, спостережуваність, безпека.
    • Концепції Tools і Function Calling в LLM.
    • Шаблони агентів: ReAct Agent, Planner-Executor, Knowledge Retriever Agent.
    • Як Vertex AI Agent Engine співвідноситься з LangChain та іншими фреймворками.
    • Практичні приклади використання.
  8. Створення та розгортання AI-застосунку в GCP.
    • Архітектура типового Generative AI-додатка на GCP:
      Frontend (Streamlit / Gradio) -> LLM-логіка (Gemini API) -> дані (Vector Search 2.0 / RAG) -> агентна оркестрація (Agent Engine).
    • Розробка пайплайна "prompt -> response -> validation ->storage".
    • Інтеграція з Vertex AI Agent Engine: додавання дій (tools), підключення зовнішніх API та контекстів.
    • Тестування та налагодження промптів (логування, метрики, діагностика відповідей).
