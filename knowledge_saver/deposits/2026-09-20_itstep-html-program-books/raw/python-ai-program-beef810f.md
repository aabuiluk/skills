Title: Програма курсу Штучний інтелект з використанням Python Версія 2.0.0

Програма курсу Штучний інтелект з використанням Python Версія 2.0.0
Artificial Intelligence in Python
Для груп курсу Python AI
Тривалість курсу – 50 пар
Версія 2.0.0

Мета курсу
Навчити студента фундаментальним знанням у галузі штучного інтелекту. Навчити створенню застосунків на Python з використанням штучного інтелекту.

Після закінчення курсу слухач буде:
- Розуміти основні принципи штучного інтелекту та машинного навчання.
- Працювати з даними, використовуючи бібліотеки NumPy та Pandas.
- Застосовувати методи аналізу та очищення даних для підготовки навчальних вибірок.
- Використовувати статистичні методи та метрики оцінки моделей.
- Візуалізувати дані та результати експериментів за допомогою Matplotlib.
- Реалізовувати алгоритми навчання з учителем і без учителя.
- Створювати й навчати нейронні мережі для розв’язання прикладних задач.
- Застосовувати згорткові мережі для розпізнавання зображень та аналізу візуальної інформації.
- Розв’язувати задачі обробки природної мови (NLP) з використанням сучасних архітектур.
- Розуміти влаштування та принципи роботи Large Language Models (LLM).
- Володіти базовими та інженерними прийомами Prompt Engineering.
- Використовувати можливості Generative AI та хмарні сервіси Google Cloud Platform (Vertex AI, Gemini, Vector Search, Agent Engine).
- Застосовувати підхід RAG (Retrieval-Augmented Generation) для інтелектуальної роботи з даними.
- Розробляти та тестувати LLM-агентів і створювати Generative AI-додатки з візуальним інтерфейсом.
- Використовувати наявні LLM-моделі та API для інтеграції генеративних рішень у практичні та бізнес-проєкти.
- Використовувати фреймворк LangChain для оркестрації LLM-запитів і виклику зовнішніх інструментів.
- Застосовувати LangSmith для аналізу, валідації та моніторингу роботи LLM-систем.
- Розробляти власні LangChain-ланцюжки з використанням PromptTemplate, Tools і Memory.
