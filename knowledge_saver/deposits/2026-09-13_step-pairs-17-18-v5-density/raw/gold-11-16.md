## ЖОРСТКА ЗАБОРОНА: «супер-скорочена» версія

**Інцидент:** material **v2** для пар **15–16** лишала короткі нотатки (`data-material-version-until="3.0"`) і ховала розгорнутий шар (`from="4.0"`). У перегляді v2 пара виглядала **порожньою / супер скороченою**. Це **помилка агента**. Повторювати **заборонено**.

### Ніколи

- «Скелет версії» (3–4 тонкі блоки) з обіцянкою «допишемо потім».
- Паралельний шар `until=N` з **урізаними** teacher-нотатками, якщо `from=N+1` — повний.
- Теорія = 1 абзац + snippet + 1 callout (картка `generate_pairs_15_50.py`).
- Завдання ITSTEP без **прикладу виконання для викладача** (кроки, очікуваний вивід, що зламати live).
- Ставити нову material-версію, яка для охоплених пар дає **менше** тексту, ніж попередня повна.

### Завжди

- Нова версія = **щільніше або так само щільно**, ніколи тонше за еталон 11–16 / v4 15–16.
- Якщо додаєте `from="X.0"` розгорнутий шар — **не** залишайте для тих самих пар коротший `until` як єдиний контент при перегляді старішої версії *для цих пар*; або не публікуйте стару версію на ці пари в `overrides`, або тримайте спільний (untagged) повний шар.
- Завдання: умова + «Звідки дані і навіщо» + орієнтир + **`.lh-teacher-note` з прикладом виконання** (живе кодування, навмисна помилка, очікуваний `# ->`, критерій здачі по хвилинах). X.1 — без готового файлу студенту.

## Планка густини (мінімум = як 11–16)

| Критерій | Мінімум |
|----------|---------|
| Статей `article.block` | ≥ 16 |
| `<p class="lead">` | ≥ 10, перед поясненням і перед «Приклад ·» |
| Окремі timed «Приклад ·» | ≥ 4 |
| Timed сума | рівно **80**; extra / deep-study / teacher-deep **поза** 80 |
| Після ITSTEP | checkpoint **3** + exit **4** |
| Практика | ≥ 20 хв |
| `.lh-teacher-note` | на **кожному** змістовному блоці (теорія, приклад, task, checkpoint, exit) |
| Нотатка викладача | Коротко · На дошці · Живе кодування · Навмисна помилка · Питання групі · Рішення · Час |
| Завдання | teacher walkthrough з числовим/табличним очікуванням |
| `teacher.md` | повний хронометраж + дошка + типові поломки |
| Код | `ast.parse` clean; `# ->` де є вивід |

Порядок:

```
теорія + приклади (годинник)
→ extra (без HH:MM)
→ ITSTEP 1–N (з teacher execution example)
→ checkpoint (3) → exit (4)
→ deep-study (take-home)
```

Непарна: 18:30–19:50. Парна: 20:00–21:20.
