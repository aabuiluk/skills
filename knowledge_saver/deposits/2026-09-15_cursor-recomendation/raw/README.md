# CursorRecomendation

Окремий шар матеріалів для покращення 50 пар курсу «Штучний інтелект із використанням Python» за [офіційною програмою ITSTEP 2.0.0](https://materials.itstep.org/content/beef810f-be75-4b3c-9c1b-a8124a1a4b01/uk).

Папка **не підключена** до студентської публікації. Чинні `presentation.html`, `versions.json` і `public_plan.json` не змінюються цим шаром.

## Структура

Повторює курс: `mNN/pair_NN/`. У кожній парі:

| Файл | Для кого | Зміст |
|---|---|---|
| `students.md` | студенти | новий акцент, поняття, приклад, пастка, мінісамостійна, джерела |
| `teacher.md` | викладач | відкриття, дошка, live coding, питання, помилки, таймінг, інтеграція |
| `exercises.md` | обидва | розминка, core, дослідження першоджерела, stretch, рубрика |
| `examples.py` | обидва | короткий відтворюваний демо-код |
| `data/README.md` | обидва | датасет, схема, ліцензія, leakage |
| `data/sample.csv` | обидва | 8 рядків для форми коду |

## Як користуватися

1. Відкрийте ту саму пару в `python_ai_step`.
2. Прочитайте «Унікальність» у `teacher.md` — не копіюйте те, що вже є в лекції.
3. Виберіть 10–20 хв опційного шару або stretch додому.
4. Переносьте студентський текст у презентацію голосом «ви / зверніть увагу».
5. Звіряйте URL у [SOURCES.md](SOURCES.md) перед заняттям — API хмар змінюються.

## Унікальність

Матеріал зібрано як **доповнення**: інший кут, інший датасет, діагностика, протокол оцінки, опційний cloud/framework-track. Частково спирається на аудит повноти `reports/python_ai_step_topic_completeness_audit_2026-09-15.md` (історія як операційні визначення, log loss/XGBoost як PR+early stopping, Heart Disease, pneumonia patient split, seq2seq+HF, реальний Vertex/LangChain як optional track).

Приклади `examples.py` з модулів 2–5 очікують NumPy, pandas, scikit-learn або PyTorch — той самий стек, що й лекції. Частина пар модулів 1 і 6–10 запускається стандартною бібліотекою Python.
