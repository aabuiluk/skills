# knowledge_saver

Immutable archive of hard-won knowledge for this `skills` repo.

**Originals stay forever** under `deposits/*/raw/`. Derived skills and edits use
copies only. Workflow: skill [`knowledge-saver`](../.cursor/skills/knowledge-saver/SKILL.md).

```text
knowledge_saver/
├── README.md
├── INDEX.md                 # catalog of deposits
└── deposits/
    └── YYYY-MM-DD_<slug>/
        ├── ORIGIN.md        # provenance
        ├── raw/             # do not edit or delete
        └── notes/           # optional, editable
```
