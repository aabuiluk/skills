# Типи блоків і зони

Читай цей файл, коли треба зібрати або перевірити скелет пари. Не переписуй типи з памʼяті. Не звіряйся з HTML-прототипом чи живою парою.

## Чотири зони

| Зона | Де на сторінці | Що тримає |
|------|----------------|-----------|
| `chrome` | верхня панель журналу | кнопки навігації й режиму, не лекція |
| `rail` | ліве меню | один блок `toc`; пункти з заголовків `stage` |
| `stage` | головна колонка | лекція 80 хв + extra + teacher |
| `notebook` | права панель | комірки Python, дзеркало `<pre>` зі `stage` |

Не клади теорію в `chrome`. Не клади кнопки журналу в `stage`. Не дублюй TOC вручну в `stage`.

## Типи

Кожен тип має домашню зону. `kind` — колір/роль бейджа.

| type | kind | Зона | Сюди піде |
|------|------|------|-----------|
| `chrome` | chrome | chrome | Елемент верхньої панелі: «До плану», номер пари, версія студентів, превʼю, зошит, попередня/наступна, завантажити. |
| `toc` | nav | rail | Бічне меню пари. Пункти збираються з заголовків блоків лекції, кожен з якорем на свій `id`. |
| `banner` | main | stage | Шапка пари: kicker, назва, lead, пігулки таймінгу на 80 хв і список цілей. |
| `theory` | main | stage | Студентська теорія: lead-місток, один факт, пояснення, далі схема або код і callout «Зверніть увагу». |
| `example` | main | stage | Короткий runnable приклад до абстракції: код до 15 рядків, підпис «Приклад · N», очікуваний вивід `# ->`. |
| `diagram` | main | stage | SVG-карта кроку. На кожному підписаному блоці схеми — тултіп з тим самим фактом, що в реченні. |
| `code` | main | stage | Комірка Python у лекції: `language-python`, позначка RUNNABLE або EXCERPT. Журнал дзеркалить її в зошит. |
| `callout` | main | stage | Врізка до студента: «Зверніть увагу», «Коротко», «Джерела» або «Орієнтир». Без голосу «поясніть студентам». |
| `trap` | main | stage | Типова плутанина теми. До читача: «часто плутають… зверніть увагу…», не «студенти часто». |
| `extra` | deep | stage | Опційний шар для сильніших. Не входить у 80 хв. У таймінг-стрічці — **(опц.)**. |
| `teacher` | deep | stage | Текст лише для викладача: дошка, live, навмисна помилка, відповіді. Студенту блок не видно. |
| `task` | task | stage | Офіційне завдання: «Звідки дані і навіщо», умова, лінк LMS, практика X.1 без готового файлу. Розвʼязок — у нотатці викладача. |
| `homework` | task | stage | Офіційне ДЗ перед stretch. Умови з аркуша програми. Еталонний код лише в блоці викладача. |
| `checkpoint` | check | stage | Мікроперевірка ~3 хв: 4 короткі питання і «Де перечитати». Після кластера практика, не одразу після першого завдання. Фінальний Checkpoint — після всіх `#itstep-task-N`. |
| `exit` | check | stage | Вихідна перевірка ~4 хв: 1–2 питання і «Де перечитати». Входить у 80 хв. |
| `notebook` | tool | notebook | Бічна панель Python у браузері. Комірки з `<pre>` лекції; Запуск / Restart, ядро Pyodide. |

## Порожній слот

Якщо джерела на блок немає — слот **лишається**, `text` = `Потребує допрацювання`. Не викидати тип зі схеми. Заповнення пізніше — `growth_of_cource_building`.
