- Теорія = 1 абзац + snippet + 1 callout.

- Орієнтир завдання, який покладається на змінні з попереднього блоку або на `__file__` у вебі.

## Обовʼязкова планка (як 15–16)

| Критерій | Мінімум |
|----------|---------|
| Статей `article.block` | ≥ 16 (теорія+приклади+extra+ITSTEP+checks+deep) |
| `<p class="lead">` | ≥ 10, **перед** кожним поясненням і перед кожним «Приклад ·» |
| Приклади до абстракції | ≥ 4 окремих timed-блоки `Приклад · …` |
| Timed сума | рівно **80**; extra і deep-study **поза** 80 |
| Після ITSTEP | `checks`: checkpoint **3 хв** + exit ticket **4 хв** (`kind_label`: перевірка) |
| Практика | `practice_min = 80 − theory − checks`, і **≥ 20** |
| `teacher.md` | повний `teacher_md_full` (цілі, хронометраж, дошка, живе кодування, типові помилки викладачу) |
| Завдання | `why`/`context` → «Звідки дані і навіщо»; X.1 без розвʼязку |
| Код | `ast.parse` clean; очікуваний вивід `# ->`; `loss.item()` де треба число |
| Візуал | SVG/схема, якщо поняття просторове (шар, згортка, пайплайн) |

Порядок блоків:

```
теорія + приклади (годинник)
→ extra (без HH:MM)
→ ITSTEP практикум + завдання 1–N
→ checkpoint (3) → exit-ticket (4)
→ deep-study (без годинника)
```

Непарна пара: 18:30–19:50. Парна: 20:00–21:20.

## Як писати нову пару

1. `query_teacher_kb.py --note` і `--sheet` (якщо є аркуш).
2. Новий файл `_rich_pairs_{odd}_{even}.py` з `pair_N()` як у 15–16.
3. `specs()` модуля: `from _rich_pairs_X_Y import pair_N as rich_N` і поставити rich **першими** замість тонких `pair_N()`.
4. Запуск лише цих пар (не весь `generate_pairs_15_50.py`):

```bash
python3 backend/data/courses/python_ai_materials/tools/rewrite_rich_pairs.py --pairs 17,18
```

5. `verify_pair_windows.py` (не «виправляти» чужі 7–8, якщо не просили).
6. `build_lesson_materials_1_14.py` після вебу.
