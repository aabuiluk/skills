# `/courses` і `/course`

Один catalog, дві поверхні. Розклад пар пишеться **повністю**. Хто що бачить — окремий гейт, не другий план.

Еталон журналу:

| Хто | Шлях UI | Що в меню |
|-----|---------|-----------|
| Викладач | `/courses/{slug}` | Усі модулі й усі пари catalog + галочки публікації |
| Студент | `/course/{slug}` | Лише пункти з галочкою |

Приклади золота: [меню викладача](https://csctemplate.pythonanywhere.com/courses/python_ai_step) vs [меню студента](https://csctemplate.pythonanywhere.com/course/python_ai_step).

Фронт: `ADMIN_COURSE_PATH = "/courses"`, `PUBLIC_COURSE_PATH = "/course"`. Адмін-простір — якщо URL починається з `/courses`.

## Меню

Однакова форма акордеона (модуль → пара → офіційний syllabus). Різниця — **склад і хром**, не формулювання пунктів.

**`/courses` (викладач)**

- Каталог `?all=1`: усі 50 пар, навіть без галочки.
- Біля кожного пункту: галочка «відкрити на публічній сторінці» + копіювання блоку.
- Roadmap / overview завжди видно в акордеоні (щоб можна було опублікувати).
- Чіп «публічний перегляд» веде на `/course/{slug}`.
- Підказка: галочка відкриває пункт студентам. Галочки **не ставити кодом** (`public_plan.json` не чіпати).

**`/course` (студент)**

- Пари й roadmap лише з `public_plan.json`.
- Немає галочок, немає `teacher.md` у списку файлів.
- Модуль без жодної опублікованої пари не показується.
- Неопублікована пара — 404, не «скоро буде» в меню.

`catalog.json` цього скіла = вигляд `/courses`. Студентський `/course` — фільтр того самого JSON.

## Пара після кліку

Той самий `presentation.html`. Різниця — query й оболонка.

| | `/courses/.../pairs/N` | `/course/.../pairs/N` |
|--|------------------------|------------------------|
| Файл лекції | `?teacher=1` | без `teacher` |
| Нотатки `.lh-teacher-note`, таймінг | видно | сховані CSS |
| `teacher.md` | є | немає |
| Версія матеріалу | `active` (редактор) | `student_active` |

Не роби окремий «студентський syllabus». Офіційні пункти меню спільні.

## Гейт публікації

`backend/data/public_plan.json`:

```json
{
  "python_ai_step": { "roadmap": true, "pairs": [1, 2] }
}
```

- Немає жодної галочки й roadmap — курс **не в публічному каталозі** (`is_listed`).
- Цей скіл **не записує** `public_plan.json` і не проставляє галочки.
- Золото step: галочка в `/courses/python_ai_materials` теж відкриває ту саму пару на `/course/python_ai_step` (`student_visible_pairs`). Не дублюй галочки на step кодом.

## Що емітити

У `thematic-plan.md` коротко два URL:

```text
Викладач: /courses/{slug}  — повний план
Студент:  /course/{slug}   — лише опубліковані пари
```

Не емітити два різних розклади. Не публікувати всі пари «щоб студенти одразу все бачили».
