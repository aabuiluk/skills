# Лінзи тематики

Формат меню не змінюється. Змінюється **що вважати однією 80-хв сімʼєю** і коли split / pack.

Читай цю файл, коли програма не про Python AI, або коли модуль змішаний (теорія + інструмент + кейс).

## Як обирати лінзу

1. Візьми назву курсу / модуля (мова, математика, Python Core, DS, ML, хмара, іспит).
2. Застосуй одну лінзу нижче до **класифікації пунктів**.
3. Budget модуля все одно з програми. Лінза лише розподіляє слоти.

## Інструменти даних і API бібліотек

NumPy, Pandas, matplotlib, SQL, Git, IDE.

Одна бібліотека / поверхня API ≠ одна пара, якщо в модулі є запас слотів: спочатку обʼєкти й перші операції, потім решта методів або типи графіків. Дві бібліотеки в одній парі — лише місток (ndarray → Series), не «весь pandas + весь numpy».

## Статистика / математика

Одна сімʼя формул на пару: середні окремо від розподілів; похідна окремо від градієнтного спуску, якщо програма їх розвела. Не пакуй «всю статистику модуля» в одну пару, коли бюджет 2+.

## Алгоритми ML (supervised / unsupervised)

Типовий ланцюжок, якщо слотів вистачає: поняття задачі → метрики → як навчається → бібліотека / кілька змінних → іменований lab → pack решти алгоритмів тієї ж гілки.

Sibling-моделі (дерево / ліс / бустинг) пакуються, коли lab уже зʼїв слот.

Зниження розмірності, кластеризація, рекомендації — різні сімʼї: кожна може зайняти 2 пари (метод + варіант/кейс), як M7.

## Нейромережі та CV / NLP

Ідея моделі окремо від фреймворку, якщо програма має обидва пункти. Кейс (медицина, MNIST, пневмонія, seq2seq) — lab. Препроцесінг мови (NLTK) не змішувати в одну пару з Transformers, якщо є 5 слотів на модуль.

## GenAI, хмара, фреймворки оркестрації

Один нумерований пункт ≈ одна пара, поки не доведеться join сусідів («контекст + платформа», «агенти + деплой»). Якщо пунктів менше, ніж слотів — останній слот = практикум на моках, без нової теми.

Не клади RAG, агентів і деплой в одну пару, коли бюджет 6.

## Мова програмування (Python Core тощо)

Одна синтаксична сімʼя + практика = пара (цикли; функції; ООП; файли). Інструмент (Jupyter, Git, IDE) — окрема пара, якщо він є пунктом програми. Не пакуй два розділи граматики мови + контрольну в одну 80-хв.

## Іноземна / гуманітарна дисципліна

Одна комунікативна мета на пару (час + практика; тема письма). Контрольна / іспит — останній модуль, не додаток до граматики.

## Іспит і захист

Окремий модуль. Зазвичай підготовка (чеклист + пробні задачі) і виступ / робота. Не розмазуй іспит по всіх модулях.

## Якщо лічби пар немає

Орієнтир, не догма:

- standard пункт ≈ 1 пара
- fat / lab ≈ +1
- два thin siblings ≈ 1 пара
- іспит ≈ 2 пари, якщо він у програмі є

Покажи цю арифметику користувачу перед emit.
