# strategy_of_cource_building

Одиниця роботи — **пара в меню**, не слайд.

Еталон: тематичний план [python_ai_step](https://csctemplate.pythonanywhere.com/courses/python_ai_step), зроблений з програми [Штучний інтелект з Python 2.0.0](https://materials.itstep.org/content/beef810f-be75-4b3c-9c1b-a8124a1a4b01/uk) (50 пар × 80 хв).

Джерело еталону: [gold-python-ai-step.md](references/gold-python-ai-step.md). Лінзи за тематикою: [topic-lenses.md](references/topic-lenses.md). Поля виводу: [output-schema.md](references/output-schema.md). Дві поверхні журналу: [courses-vs-course.md](references/courses-vs-course.md).

Source deposit: `knowledge_saver/deposits/2026-09-16_strategy-of-cource-building/`.

## Коли

Користувач дає програму (URL, PDF, markdown, вставка) і просить розкласти на пари, меню курсу, catalog, тематичний план. Не чекай назви скіла.

Цей скіл **не** пише `presentation.html`, `teacher.md`, роздаток. Далі, якщо просять матеріали, — `teacher-materials-skill` / `common_lesson`.

## Дві поверхні: `/courses` і `/course`

Один розклад. Два URL. Деталі: [courses-vs-course.md](references/courses-vs-course.md).

| | Викладач | Студент |
|--|----------|---------|
| UI | `/courses/{slug}` | `/course/{slug}` |
| Меню | увесь catalog | лише галочки `public_plan` |
| Лекція | `?teacher=1`, нотатки, `teacher.md` | без teacher-хрому |

Емітити **повний** план (вигляд `/courses`). Не ставити галочки й не писати `public_plan.json`. Студенти побачать пару, коли власник поставить галочку.

Не робити другий «студентський» тематичний план з іншими назвами.

## Форма меню (спільна)

Hero: назва, тривалість (`N пар · по 80 хв`), кількість модулів, subtitle, мета.

Тематичний план — акордеон модулів:

```text
Модуль K. {офіційна назва}
N пари · пари {start}–{end}
  overview
  результати навчання
  Пара {global_index}. {назва 80-хв одиниці}
    1. {офіційний пункт програми}
       • {офіційний підпункт}
```

Назва пари — що відбувається за 80 хв. Блоки syllabus — **формули програми**, не переказ.

## Пайплайн

```
1. Intake     програма як є
2. Budget     модулі × кількість пар; 80 хв за замовчуванням
3. Classify   кожен нумерований пункт: thin / standard / fat / lab / exam
4. Allocate   split / 1:1 / join / pack / practicum — у бюджеті модуля
5. Name       title + 3–4 objectives
6. Cover      кожен офіційний пункт зʼявився; зайвого немає
7. Emit       thematic-plan.md + catalog.json
```

### 1. Intake

Зібрати: назва, мета / «слухач буде», тривалість, модулі, нумеровані пункти з вкладеними підпунктами, іспит, обовʼязкові пререквізити.

Якщо джерело — URL: читай сторінку (програма), не внутрішні лекції й не презентації пар.

**Готово:** дерево `module → numbered item → nested items`, без вигаданих тем.

### 2. Budget

- Тривалість пари = з програми, інакше **80 хв** (академічна пара ITSTEP).
- Якщо програма вже каже «модуль K — N пар» — **не перекидати** пари між модулями.
- Якщо є лише години: 1 пара ≈ 2 академічні години ≈ 80 хв.
- Якщо лічби немає: оціни за [topic-lenses.md](references/topic-lenses.md), покажи оцінку, не мовчки округлюй.

Модуль іспиту / захисту — окремо, зазвичай **2 пари** (підготовка + іспит), якщо програма не каже інакше.

**Готово:** таблиця `модуль → N пар`, сума = заявлений тотал.

### 3. Classify

Кожен нумерований пункт:

| Клас | Ознака | Наслідок |
|------|--------|----------|
| thin | 1–2 підпункти, огляд, «види X» | можна join з сусідом |
| standard | 3–6 підпунктів, одна сімʼя понять | 1:1 |
| fat | дві сімʼї в одному пункті (обʼєкти vs методи; середні vs розподіли) | split, якщо є слоти |
| lab | іменований кейс, багато кроків препроцесингу / захисту | власна пара |
| exam | іспит, захист, підсумок курсу | 1–2 пари в останньому модулі |

**Готово:** кожен пункт має клас.

### 4. Allocate

Працюй **усередині модуля**, не глобально.

1. Спочатку розклади lab і fat.
2. Standard — по одній парі.
3. Thin — приєднуй до сусіда тієї ж сімʼї («приклади», «реалізація в бібліотеці», «практичні приклади»).
4. Якщо слоти ще лишились — split fat, або додай **інтеграційний практикум** на останню пару модуля (повтори останній пункт як застосування, не вигадуй нову тему).
5. Якщо слотів не вистачає — **pack remainder**: кілька sibling-алгоритмів / патернів в одну пару; title перелічує сімʼї.

Межа спліту — **межа сімʼї понять**, не середина пояснення (не «згортка» окремо від «фільтрів», якщо це один механізм).

Повний нумерований пункт можна розрізати на дві пари з **тим самим** `syllabus.title` і різними `items` (золото: numpy vs pandas methods).

**Готово:** кожна пара має 1–3 syllabus-блоки; сума пар модуля = бюджет.

### 5. Name

- `title` — конкретна 80-хв одиниця, не копія номера модуля. Можна звузити («Регресія з однією змінною») або розвести спліт («NumPy: …» / «Pandas: …»).
- `objectives` — 3–4 перевірювані дії («побудувати», «порівняти», «пояснити»), не «ознайомитися».
- Мова як у програмі.
- Overview модуля і learning outcomes — короткий парафраз програми, не нові теми.

**Готово:** у меню можна прочитати пару без слайдів.

### 6. Cover

- Кожен нумерований пункт програми є `syllabus.title` принаймні в одній парі.
- Підпункти розкладені, без сиріт.
- Не додавай тем, яких немає в програмі.
- Не переписуй офіційні формулювання syllabus «краще».

Покажи матрицю: пункт програми → `Пара N`.

**Готово:** матриця без дірок і без зайвих рядків.

### 7. Emit

Два артефакти (схема: [output-schema.md](references/output-schema.md)):

1. `thematic-plan.md` — повний вигляд `/courses` + два URL (`/courses` викладач, `/course` студент).
2. `catalog.json` — `modules` + `pairs` (увесь курс, не зріз публікації).

Зупинись. Не створюй каталоги `mXX/pair_YY/` і не став галочки публікації.

## Заборонена форма

Не: одна пара = весь модуль.
Не: «пари 1–50» з порожніми назвами.
Не: переписані пункти програми замість verbatim syllabus.
Не: презентація замість меню.
Не: перекидання пар з модуля в модуль всупереч програмі.
Не: окремий розклад «для студентів» і «для викладача».
Не: публікація всіх пар у `public_plan.json`.

## Перевірка

- Сума пар = бюджет програми.
- Кожен модуль у меню: назва, N пар, діапазон global_index, overview, outcomes, список пар.
- Кожна пара: global_index, title, duration_min, syllabus з офіційними пунктами, 3–4 objectives.
- Тематика змінює **пакування** (лінзи), не ламає формат меню.
- У плані є обидва URL: `/courses/{slug}` і `/course/{slug}`. Catalog повний, без галочок.
