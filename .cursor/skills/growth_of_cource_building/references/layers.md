# Шари росту

Читай цей файл, коли класифікуєш, **куди** лягає нове джерело. Типи слотів — у `tactic_of_cource_building/references/block-types.md`. Порядок слотів не вигадуй тут.

## Чотири шари на сторінці

| Шар | Хто бачить | 80 хв | Сюди graft, якщо |
|-----|------------|-------|------------------|
| required | студент | так | факт програми, без якого пару не провести |
| extra | студент | ні | глибше / друга стаття / акцент інструмента |
| teacher | викладач | ні | дошка, live, навмисна помилка, еталон |
| take-home | студент після пари | ні | deep-study, ДЗ поза вікном |

Homework з аркуша програми — `homework` (умова в 80-хв контурі як слот, еталон коду в teacher). Deep-study — після Exit.

## Material-версія

Журнал показує шар `data-material-version-from` / `until`. Ріст = **новий from**, не заміна файлу.

Правило густини: версія N+1 для тих самих пар **не тонша** за повний шар N. Спільний (без тега) повний текст можна лишати видимим у всіх версіях.

Антиеталон: v2 пар 15–16 лишала короткі нотатки (`until="3.0"`) і ховала розгорнутий шар (`from="4.0"`). У перегляді v2 пара здавалась порожньою.

`student_active` на нову версію в `python_ai_step` потребує **усі 50 пар** в `overrides`, інакше решта відкотиться. Не чіпай `overrides`, якщо користувач просив лише карту росту однієї пари.

## Overflow

Джерело цінне, але required уже 80:

1. `extra` одразу після кластера, якого стосується
2. якщо extra кластера вже thick — deep-study
3. якщо це новий викладацький сценарій — `teacher`
4. якщо змінює формат усієї пари (карта кроків, Коротко/Детально) — нова version-from, required не різати

Не перетворюй extra на required без перерахунку хвилин і без явної просьби змінити вікно 80 хв.

## Freeze vs grow

Freeze (не чіпати ідентичність):

- `id`, `type` core-слота
- речення факту, яке вже в карті кроків
- required хвилини блоку
- офіційний пункт syllabus у банері

Grow (можна додавати):

- приклад / схема / trap / callout поруч
- `sources[]`
- teacher-близнюк після кластера
- extra / deep-study / нова version-from
- термін у словнику

## Не лише HTML

Той самий принцип на сусідах пари:

| Файл | Freeze | Hook |
|------|--------|------|
| `teacher.md` | заголовки хронометражу | секція «коли з’явиться стаття» |
| словник | ключ терміна | порожнє `def`, дописати пізніше |
| роздаток | номер завдання | X.1 без готового файлу |

Не заводь паралельну структуру «чернетка v2», яка ховає робочу пару.
